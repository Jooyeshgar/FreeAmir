# ایجاد سند حسابداری

از مسیر **حسابداری ← ایجاد سند**، ردیف‌های بدهکار و بستانکار یک رویداد مالی را ثبت کنید. شرکت و سال مالی فعال را پیش از شروع کنترل کنید.

1. تاریخ و عنوان سند را وارد کنید.
2. برای هر ردیف، سرفصل، شرح و مبلغ بدهکار یا بستانکار را تعیین کنید.
3. جمع دو طرف را برابر کنید و سند را ذخیره کنید؛ سپس وضعیت آن را در [فهرست اسناد](../document-list/accounting-documents.md) بررسی کنید.

سند نامتوازن پذیرفته نمی‌شود. تأیید، ویرایش، انتقال و چاپ از صفحه سند یا فهرست اسناد انجام می‌شود و ممکن است به مجوز جداگانه نیاز داشته باشد.
