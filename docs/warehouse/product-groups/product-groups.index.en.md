# Product groups

Use **Warehouse → Product Groups** to classify products. Configure the inventory account before creating a group; otherwise the creation form redirects to settings. A group name is required and limited to 20 characters. VAT is optional and must be between 0 and 100; the tax product/service identifier (`sstid`) is optional too.

Open a group from the list to inspect its income, sales-return, cost-of-goods, and inventory accounts and the number of member products. You can edit it there. If dependencies block deletion, the page displays the reason; check related products before deleting.
