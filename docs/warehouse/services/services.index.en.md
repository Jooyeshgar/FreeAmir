# Services

In **Warehouse → Services**, view, search, create, and edit services used on invoices. Name and service group are required. Leave the code blank for the next automatically assigned number; a supplied code must be unique in the active fiscal year. Selling price and VAT are optional.

Filter the list by service or group name. Export CSV or import a CSV/TXT file of up to 5 MB; the import result reports created and updated services and created groups. Check invoice and account dependencies before deleting a service.
