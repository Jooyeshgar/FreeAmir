# نقشه راه امیر

امیر یک پروژه در حال توسعه است. دسترسی کاربران به سال مالی جداگانه تعیین می‌شود؛ فهرست زیر قابلیت‌های تکمیلی و اولویت‌های آینده را نشان می‌دهد.


## در حال توسعه

- تعریف نقش‌ها و مجموعه مجوزهای اختصاصی برای هر شرکت

## تکمیل‌شده

- **گزارش فعالیت‌ها:** ثبت تغییرات و پیگیری فعالیت‌ها در پنل مدیر کل
- **پشتیبانی موبایل / PWA:** اپلیکیشن موبایل یا PWA برای دسترسی آسان‌تر
- **گزارش‌های پیشرفته:** گزارش‌های مالی و مدیریتی پیشرفته‌تر

## ایده‌های آینده

- **نقش‌ها و مجوزها:** تعریف نقش‌ها و مجموعه مجوزهای اختصاصی برای هر شرکت
- **فرآیندهای تأیید:** سیستم تأیید مراحل مختلف عملیات مالی
- **گسترش API:** نوشتن API کامل برای اتصال به سیستم‌های جانبی

## مشارکت

اگر ایده‌ای برای بهبود امیر دارید، از طریق [GitHub Issues](https://github.com/Jooyeshgar/FreeAmir/issues) مطرح کنید.
