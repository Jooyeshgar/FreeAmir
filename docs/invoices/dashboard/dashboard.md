# میزکار فاکتورها

مسیر منو: **فاکتورها ← میزکار فاکتورها**. [میزکار را در برنامه باز کنید]({{ site.app_url }}/invoices/dashboard). تاریخ شروع و پایان را انتخاب و «اعمال» را بزنید؛ «بازنشانی» فیلتر را برمی‌گرداند.

کارت‌ها فروش محصول، بهای تمام‌شده، سود و حاشیه سود ناخالص، تعداد فاکتورهای فروش و خرید و مبلغ برگشت و ابطال را نشان می‌دهند. درآمد محصول خالصِ برگشت فروش و مالیات بر ارزش افزوده است؛ سود ناخالص از تفاوت درآمد و بهای تمام‌شده به دست می‌آید. این صفحه برای مرور روند است و جای تطبیق فاکتور، سند و گزارش حسابداری را نمی‌گیرد.

اگر عددی غیرمنتظره است، ابتدا بازه تاریخ و شرکت/سال مالی فعال را کنترل کنید، سپس از پیوند فهرست فاکتورها به رکوردهای همان بازه بروید. [راهنمای فاکتور فروش](../sells/sell/sell.md) و [راهنمای فاکتور خرید](../purchases/buy/buy.md) جزئیات ثبت را توضیح می‌دهند.
