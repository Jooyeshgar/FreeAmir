# Sales-return accounting example

## Sales return

### Event

In Mordad (the fifth month), the company sold goods:

- It received 300,000 rials in cash.
- The remaining sale amount was on credit.
- The goods cost 240,000 rials.

Some of the goods have now been returned.

### Required posting

| Description | Debit | Credit |
|---|---:|---:|
| Sales returns and allowances | 30,000 | |
| Customer | | 30,000 |
| Inventory | 24,000 | |
| Cost of goods sold | | 24,000 |

The partial return therefore reduces net sales and increases inventory.

For the purchase-return posting, see the [purchase-return guide](../../purchases/return-buy/return-buy.en.md#accounting-example).
