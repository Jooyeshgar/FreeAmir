# Service Purchase Return

Menu path: **Invoices → Purchases → Service Buy Return**. This option lists service returns using the system's purchase-return type with a service filter. [Open the list in the app]({{ site.app_url }}/invoices?invoice_type=return_buy&service_buy=1).

To create a return, select the approved service-purchase invoice as the source; the counterparty must match. Compare the selected services, amount, discount, and tax with the remaining returnable balance, then save or approve. The form accepts services, not goods, so do not expect a goods inventory outflow.

The [purchase return guide](../return-buy/return-buy.en.md) explains source validation, earlier returns, payments, and document dependencies. After approval, check the reverse service-purchase document and counterparty balance.
