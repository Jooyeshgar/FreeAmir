# برگشت از خرید خدمت

مسیر منو: **فاکتورها ← خرید ← برگشت از خرید خدمت**. این گزینه فهرست برگشت‌های خدمت را با نوع سیستمی «برگشت از خرید» و فیلتر خدمت نشان می‌دهد. [فهرست را در برنامه باز کنید]({{ site.app_url }}/invoices?invoice_type=return_buy&service_buy=1).

برای ایجاد برگشت، فاکتور خرید خدمتِ تأییدشده را به‌عنوان مرجع انتخاب کنید؛ طرف حساب باید یکسان باشد. خدمت‌های موردنظر، مبلغ، تخفیف و مالیات را با مانده قابل برگشت تطبیق دهید، سپس ذخیره یا تأیید کنید. فرم خدمت را می‌پذیرد، نه کالا؛ بنابراین گردش خروج کالای انبار نباید انتظار داشته باشید.

اعتبارسنجی فاکتور مرجع، برگشت‌های قبلی، پرداخت و وابستگی‌های سند در [راهنمای برگشت از خرید](../return-buy/return-buy.md) آمده است. پس از تأیید، سند معکوس خرید خدمت و مانده طرف حساب را کنترل کنید.
