# Activate Confirmed Invoices

Menu path: **Invoices → Activate Confirmed Invoices**. [Open the list in the app]({{ site.app_url }}/invoices/inactive). This page shows invoices in **approved inactive** status and their related inactive ancillary costs. It does not delete or return an invoice.

Before acting, check each row's type, number, customer, date, and amount, and open the invoice link for details. Inspect any ancillary-cost row showing a warning. **Approve All** sends a bulk activation request; because several records can change, reconcile dependencies and inventory/document effects with the responsible accountant first.

Afterward, check the result message and the purchase invoice list. If a record was not activated or a conflict appears, review that invoice and its related ancillary cost separately. The [general invoices guide](../README.en.md) explains statuses and checks after posting.
