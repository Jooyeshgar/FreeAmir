# راهنمای فاکتور‌ها

این صفحه نقشهٔ راه فاکتور‌هاست. برای ساده‌تر‌شدن استفاده، راهنمای هر نوع فاکتور و هر عملیات وابسته در صفحهٔ جداگانه آمده است.

> **اصل مهم:** ذخیرهٔ فاکتور، تأیید و ساخت سند حسابداری، ثبت پرداخت، ساخت سند پرداخت و ارسال به سامانهٔ مؤدیان پنج مرحلهٔ جدا هستند.

## پیش‌نیاز‌ها

پیش از ثبت هر فاکتور، این موارد را کنترل کنید:

1. شرکت و سال مالی درست فعال باشد.
2. تاریخ فاکتور داخل بازهٔ سال مالی باشد.
3. مشتری/تأمین‌کننده و سرفصل حسابداری او تعریف شده باشد.
4. کالا یا خدمت و سرفصل مرتبط تعریف شده باشد.
5. انبار لازم برای فرم مشخص باشد.
6. سرفصل‌های مالیات، تخفیف، کسورات، موجودی و بهای تمام‌شده تنظیم شده باشند.
7. کاربر مجوز عملیات موردنظر را داشته باشد.

## فیلد‌ها و محاسبهٔ ردیف

حداقل یک ردیف لازم است. در هر ردیف فقط یکی از کالا یا خدمت انتخاب می‌شود.

- مقدار: عدد صحیح، حداقل ۱
- نرخ واحد: نامنفی
- تخفیف: نامنفی و حداکثر برابر مبلغ ناخالص
- مالیات: نامنفی
- شرح: اختیاری، حداکثر ۵۰۰ نویسه

فرمول:

- مبلغ ناخالص = مقدار × نرخ واحد
- مبلغ پس از تخفیف = مبلغ ناخالص − تخفیف
- مالیات = مبلغ پس از تخفیف × نرخ مالیات ÷ ۱۰۰
- جمع ردیف = مبلغ پس از تخفیف + مالیات
- جمع فاکتور = مجموع ردیف‌ها − کسورات

هنگام ویرایش، مالیات ذخیره‌شده به‌صورت مبلغ نمایش داده می‌شود؛ آن را با نرخ درصد اشتباه نگیرید.

## وضعیت‌ها

| وضعیت | کاربرد |
|---|---|
| در انتظار | ذخیره شده و هنوز تأیید نشده است |
| پیش‌فاکتور | مرحلهٔ پیشنهادی پیش از ثبت قطعی |
| آمادهٔ تأیید | برای بررسی نهایی آماده است |
| تأیید‌شده | آثار حسابداری و در صورت لزوم انبار ایجاد شده‌اند |
| لغو تأیید | آثار تأیید قبلی برگشت داده شده‌اند |
| تأیید‌شدهٔ غیرفعال | فاکتور حذف نشده و از فهرست فعال خارج شده است |
| رد‌شده | فاکتور رد شده است |
| تسویهٔ جزئی | بخشی از مبلغ پرداخت شده است |
| تسویه‌شده | مجموع پرداخت‌ها برابر مبلغ فاکتور است |

تغییر وضعیت ممکن است به پرداخت، برگشت، هزینهٔ جانبی، سند بعدی یا انتقال سال مالی وابسته باشد. پاسخ `HTTP 409` معمولاً هشدار تعارض است؛ متن آن را بخوانید و عملیات را کورکورانه تکرار نکنید.
