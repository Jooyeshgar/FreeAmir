# راهنمای ابطال فاکتور فروش

ابطال برای خنثی‌کردن کامل یک فروش تأیید‌شده به‌کار می‌رود. ابطال با حذف، برگشت از فروش یا غیرفعال‌سازی یکسان نیست.

## تفاوت عملیات

| عملیات | نتیجه |
|---|---|
| حذف | رکورد قابل حذف را از سامانه حذف می‌کند |
| برگشت از فروش | تمام یا بخشی از اقلام را با فاکتور برگشت مستقل برمی‌گرداند |
| غیرفعال‌سازی | فاکتور تأیید‌شده را از فهرست فعال خارج می‌کند |
| ابطال | فاکتور جدیدی از نوع ابطال می‌سازد و آثار فروش اصلی را معکوس می‌کند |

## شرایط ابطال

- فاکتور اصلی باید از نوع فروش و تأیید‌شده باشد.
- فاکتور نباید پرداخت داشته باشد.
- فاکتور نباید برگشت تأیید‌شده داشته باشد.
- هر فاکتور فقط یکبار ابطال می‌شود.
- تاریخ ابطال نباید پیش از تاریخ فروش اصلی باشد.
- تاریخ باید داخل سال مالی فعال باشد.
- شمارهٔ فاکتور ابطال باید عدد صحیح مثبت و در شرکت یکتا باشد.
- فاکتور منتقل‌شده به سال مالی دیگر قابل ابطال نیست.

## مراحل

1. فاکتور فروش را باز کنید.
2. از عملیات فاکتور، **ابطال** را انتخاب کنید.
3. تاریخ و شمارهٔ فاکتور ابطال را وارد کنید.
4. پیام هشدار را بخوانید و عملیات را تأیید کنید.
5. فاکتور ایجاد‌شده را از **فاکتور‌ها ← فاکتور باطل‌شده** بازبینی کنید.

## اثر حسابداری و انبار

برنامه ردیف‌ها و مبالغ فروش اصلی را در فاکتور ابطال کپی می‌کند و سپس:

- سند معکوس فروش را می‌سازد
- تراکنش معکوس انبار را برای کالا‌ها ثبت می‌کند
- اثر بهای تمام‌شده را برمی‌گرداند
- فاکتور ابطال را به فاکتور اصلی متصل و تأیید می‌کند

فاکتور اصلی حذف نمی‌شود؛ نگهداری هر دو رکورد برای ردیابی حسابرسی ضروری است.

## کنترل پس از ابطال

- [ ] فاکتور اصلی همچنان موجود است.
- [ ] فاکتور ابطال به فروش اصلی متصل است.
- [ ] مبالغ و ردیف‌های دو فاکتور متناظرند.
- [ ] سند معکوس تراز است.
- [ ] موجودی کالا به‌درستی برگشته است.
- [ ] ماندهٔ مشتری اصلاح شده است.
- [ ] هیچ پرداخت یا برگشت ناسازگار باقی نمانده است.
