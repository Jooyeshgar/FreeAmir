# فهرست مستندات امیر

**[English version](README.en.md)**

مستندات کاربردی بر اساس منوهای اصلی برنامه دسته‌بندی شده‌اند. راهنماهای نصب، توسعه و معرفی محصول در بخش عمومی قرار دارند.

## راهنماهای منوهای برنامه

| بخش | محتوا |
|---|---|
| [پورتال کارکنان](../employee-portal/README.md) | اطلاعات شخصی، حضور، فیش حقوقی و درخواست‌های هر کارمند |
| [فاکتورها](../invoices/README.md) | فروش، خرید، برگشت، ابطال، پرداخت، هزینه جانبی و سامانه مودیان |
| [حسابداری](../accounting/README.md) | اسناد، سرفصل‌ها، بانک، چک و مفاهیم حسابداری |
| [گزارش‌ها](../reports/README.md) | گزارش‌های حسابداری، نمای کلی شرکت، درآمد، هزینه و بودجه |
| [انبار](../warehouse/README.md) | کالا، خدمت، انبار، انتقال و بهای تمام‌شده |
| [منابع انسانی](../hr/README.md) | کارکنان، حضور و غیاب، حقوق، ساختار سازمان و درخواست‌ها |
| [مشتریان](../customers/README.md) | مشتریان، گروه‌ها، نظرها، انتقال اطلاعات و میزکار ارتباط با مشتری |
| [مدیریت](../management/README.md) | شروع کار، شرکت فعال و عملیات سال مالی |
