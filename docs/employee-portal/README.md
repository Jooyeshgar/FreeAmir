# راهنمای پورتال کارکنان

[فهرست مستندات](../README.md) · [English](README.en.md)

پورتال من برای مشاهده اطلاعات خود کارمند است. ورود به حساب متصل به پرونده کارمند و فعال بودن قابلیت تأیید ایمیل لازم است. این صفحات فقط اطلاعات همان کارمند را نشان می‌دهند؛ رسیدگی مدیریتی به درخواست‌ها در [منابع انسانی](../hr/README.md) انجام می‌شود.

## راهنماها به ترتیب منو

1. [پیشخوان](dashboard/dashboard.md): خلاصه حضور، درخواست‌ها، کارکرد و حقوق.
2. [حضور من](attendance-logs/attendance-logs.md): لاگ‌های روزانه و جست‌وجوی تاریخ.
3. [کارکرد ماهانه](monthly-attendances/monthly-attendances.md): خلاصه و جزئیات محاسبه ماه.
4. [فیش‌های من](payrolls/payrolls.md): مبالغ، وضعیت و اقلام حقوق.
5. [درخواست‌های من](personnel-requests/personnel-requests.md): ثبت و پیگیری مرخصی و درخواست‌های دیگر.
6. [اطلاعات من](employee/employee.md): مشاهده پرونده و ویرایش محدود حساب.

اگر پورتال خطای ۴۰۳ می‌دهد، اتصال حساب به پرونده کارمند را با پشتیبانی بررسی کنید. اگر فهرستی خالی است، از مسئول مربوط بپرسید آیا داده همان کارمند، شرکت و دوره مالی ثبت شده است. فرم ویرایش اطلاعات فعلی فقط نام، نام خانوادگی، ایمیل و گذرواژه را تغییر می‌دهد؛ برای اصلاح شماره تماس، نشانی و سایر مشخصات پرونده به منابع انسانی مراجعه کنید.
