# My Requests

In **My Portal → My Requests**, choose the Leaves, Missions, Work Orders, or Other tab and select **New Request**. Enter the request type, date, start and end times, and a reason if needed. A new request is pending; follow its approval or rejection in the list's status column.

You see only your own requests and can edit or delete a request only while it is pending. The end time cannot precede the start time. Hourly leave times must fit your work shift. An approved request may affect [monthly attendance](../monthly-attendances/monthly-attendances.en.md); ask HR to investigate discrepancies.
