# Employee Portal Guide

[Documentation index](../menu/README.en.md) · [فارسی](README.md)

My Portal is for viewing your own employee information. Access requires a signed-in user account linked to an employee record and the email-verification feature to be enabled. These pages show only that employee's data; managers process requests in [HR](../hr/README.en.md).

## Guides in menu order

1. [Dashboard](dashboard/dashboard.en.md): summary of attendance, requests, monthly attendance, and payroll.
2. [My Attendance](attendance-logs/attendance-logs.en.md): daily logs and date search.
3. [Monthly Attendance](monthly-attendances/monthly-attendances.en.md): monthly figures and daily details.
4. [My Payrolls](payrolls/payrolls.en.md): amounts, status, and payroll items.
5. [My Requests](personnel-requests/personnel-requests.en.md): submit and follow leave and other requests.
6. [My Information](employee/employee.en.md): view your record and make limited account edits.

If the portal returns HTTP 403, ask support to check the account-to-employee link. If a list is empty, ask the responsible team whether records exist for your employee, company, and fiscal period. The current information form changes only your first name, last name, email, and password; ask HR to correct phone numbers, address, or other employee details.
