# درباره امیر

مسیر منو: **مدیریت ← درباره**. این صفحه برای دیدن اطلاعات نسخه، محیط اجرا و وضعیت سامانه است؛ تنظیمات را از این صفحه تغییر نمی‌دهید.

نسخهٔ FreeAmir و نوع محیط (محلی، آزمایشی یا عملیاتی) را در بالای صفحه ببینید. بخش «اطلاعات سامانه» وضعیت حالت اشکال‌زدایی، اتصال پایگاه داده، ثبت‌نام، تأیید ایمیل، نسخه‌های PHP و Laravel، زبان، منطقهٔ زمانی و سیستم‌عامل سرور را نشان می‌دهد. اگر وضعیت اتصال پایگاه داده ناموفق است، قبل از ادامهٔ کار با مدیر سامانه هماهنگ کنید.

بخش مجوز، متن GNU GPLv3 و نام توسعه‌دهنده را نشان می‌دهد. برای دیدن کد منبع یا ثبت مشکل، پیوندهای GitHub در انتهای صفحه را باز کنید؛ گزارش مشکل را بدون رمز، کلید خصوصی یا دادهٔ مالی حساس ارسال کنید.
