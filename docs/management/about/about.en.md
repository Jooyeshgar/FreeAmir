# About Amir

Menu path: **Management → About**. This page displays the application version, runtime environment, and system status; it does not change settings.

The top of the page shows the FreeAmir version and whether the environment is local, staging, or production. The System Information section shows debug mode, database connection, registration, email verification, PHP and Laravel versions, locale, timezone, and server operating system. If the database is disconnected, contact the system administrator before continuing work.

The license section displays GNU GPLv3 information and the developer's name. Use the GitHub links at the bottom to view source code or report an issue; do not include passwords, private keys, or sensitive financial data in a report.
