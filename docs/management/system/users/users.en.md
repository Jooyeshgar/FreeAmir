# Users

Use Management → System → Users to search for users and manage their access to companies. User-management permission is required; ordinary managers see users within their authorized company scope.

## Create and edit a user

1. Search the list by name or email and, if needed, filter by email-verification status.
2. To create a user, enter a name, unique email address, a password of at least eight characters, and its confirmation. Choose at least one role and one company.
3. After saving, the application sends an email-verification notification. If delivery fails, the user has still been created; follow up on sending the notification.
4. Open Edit to change details, roles, or companies. A password is optional on edit; if supplied, it must be at least eight characters and confirmed. An employee can only be linked if that employee is not already linked to another user.

Roles determine operational permissions, while selected companies determine accessible data scope. After saving, check the roles and companies shown in the list or edit page. This operation does not itself create an accounting document.
