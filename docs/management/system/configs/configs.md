# تنظیمات حساب‌ها

از «مدیریت ← سیستم ← تنظیمات» برای تعیین سرفصل‌های پیش‌فرض مورد استفاده برنامه در عملیات مالی استفاده کنید. تغییر این کدها ممکن است بر ثبت‌های آینده اثر بگذارد؛ پیش از تغییر، سرفصل و آثار آن را با مسئول حسابداری هماهنگ کنید.

1. از فهرست، عنوان تنظیم موردنظر را باز کنید.
2. در صفحه ویرایش، سرفصل مناسب را انتخاب کنید. کد سرفصل باید عددی باشد و در فهرست سرفصل‌های ثبت‌شده وجود داشته باشد.
3. ذخیره کنید و به فهرست برگردید تا مقدار تنظیم را کنترل کنید.

این فرم فقط کلیدهای تنظیمات پشتیبانی‌شده را می‌پذیرد. اگر کد سرفصل نامعتبر باشد، تنظیم ذخیره نمی‌شود. تغییر تنظیم جایگزین اصلاح سندهای قبلی یا کنترل تراز حساب‌ها نیست؛ برای شناخت سرفصل‌ها، [راهنمای سرفصل‌ها](../../finance/subjects/subjects.md) را ببینید.
