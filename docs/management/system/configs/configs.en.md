# Account configuration

Use Management → System → Configs to select the default accounts used by financial operations. Changing these codes can affect future postings; agree on the account and its effects with the accounting owner first.

1. Open the relevant configuration entry from the list.
2. On the edit page, choose an appropriate account. Its code must be numeric and exist among registered accounts.
3. Save and return to the list to check the configured value.

The form accepts only supported configuration keys. An invalid account code is not saved. Changing a setting does not replace correcting earlier documents or reconciling account balances; see the [accounts guide](../../finance/subjects/subjects.en.md).
