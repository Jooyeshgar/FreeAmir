# بارگذاری پشتیبان

«مدیریت ← سیستم ← بارگذاری پشتیبان» در حال حاضر نام شرکت و شماره سال مالی می‌گیرد. شرکت و سال مالی در ساختار داده دو رکورد جدا هستند و فایل بازیابی باید به شناسه یک شرکت و یک سال مالی متصل شود. فرم فعلی شناسه شرکت مقصد را نمی‌گیرد و payload قدیمی `name`/`fiscal_year` را به سرویس واردسازی می‌فرستد؛ این جریان با مدل جداگانه `Company` و `FiscalYear` هماهنگ نشده است. تا اصلاح فرم و سرویس، از این صفحه برای بازیابی استفاده نکنید.

فایل ZIP حداکثر ۱۰۰ مگابایت است و باید یک فایل JSON خواندنی داشته باشد. سرویس واردسازی برای ساخت سال مالی به `company_id` و `year` نیاز دارد.

فایل خراب، ZIP بدون JSON یا JSON نامعتبر رد می‌شود. این راهنما تضمین نمی‌کند که هر فایل ZIP دلخواه با ساختار داده برنامه سازگار باشد؛ برای تهیه فایل مناسب، [دریافت پشتیبان](../backups/backups.md) را ببینید. پیش از استفاده از این صفحه پس از اصلاح، ابتدا در محیط آزمایشی بازیابی را بررسی و مانده‌ها را تطبیق دهید.
