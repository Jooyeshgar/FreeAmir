# بارگذاری پشتیبان

«مدیریت ← سیستم ← بارگذاری پشتیبان» داده‌های داخل فایل پشتیبان را به یک شرکت/سال مالی وارد می‌کند. پیش از اجرا، از داده‌های مهم نسخه پشتیبان بگیرید و در محیط آزمایشی بازیابی را امتحان کنید.

1. نام شرکت مقصد را وارد کنید؛ حداکثر ۵۰ نویسه و فقط نویسه‌های حرفی/عددی و فاصله پذیرفته می‌شود.
2. سال مالی را به‌صورت عدد صحیح مثبت وارد کنید.
3. فایل ZIP پشتیبان را انتخاب و «بارگذاری» را بزنید. اندازه فایل حداکثر ۱۰۰ مگابایت است و داخل ZIP باید یک فایل JSON خواندنی وجود داشته باشد.
4. پس از پیام موفقیت و بازگشت به صفحه اصلی، شرکت/سال مالی و نمونه‌ای از اسناد و مانده‌ها را بررسی کنید.

فایل خراب، ZIP بدون JSON یا JSON نامعتبر رد می‌شود. این راهنما تضمین نمی‌کند که هر فایل ZIP دلخواه با ساختار داده برنامه سازگار باشد؛ برای تهیه فایل مناسب، [دریافت پشتیبان](../backups/backups.md) را ببینید.
