# Companies

Menu path: **Management → System → Companies**. [Open Companies in the app]({{ site.app_url }}/management/companies). Creating or editing a company requires the relevant permission; enter information for the correct company and fiscal year.

To create a company, enter its name and fiscal year. If a previous year exists, you can copy selected data from it. After saving, verify which company is active. To change details, open the edit page from the same list.

## Moadian settings

Sending an invoice requires four company inputs: Moadian Username, Tax ID (`tax_id`), an X.509 certificate file with a `.crt` or `.cer` extension, and a PEM private-key file with a `.pem` extension. **Upload both files**; do not paste their contents into a text box. On the edit form, existing files are shown and need uploading again only when replacing them.
