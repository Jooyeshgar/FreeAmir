# Sort document numbers

Use Management → Finance → Sort Documents Number to inspect gaps in document numbers and start renumbering. This changes existing document numbers; coordinate with the accounting owner before proceeding.

## How to use it

1. Review the document statistics, date and number ranges, and the count and examples of unused numbers.
2. If there are gaps, select “Start Sorting Numbers” and confirm. The application will not start if there are no unused numbers.
3. Follow the progress bar and processed-document count until the status is “Completed.” An in-progress operation resumes when you return to the page.

**Warning:** Once numbers change, previously printed documents are no longer valid. Accounting reports, especially printed copies, may also become invalid. Reconcile the result with the [document list](../../../accounting/document-list/accounting-documents.en.md) and print new copies if needed.
