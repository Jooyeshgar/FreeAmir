# شیفت‌های کاری

مسیر: «مدیریت ← منابع انسانی و سازمان ← شیفت‌های کاری». شیفت را پیش از ایجاد پرونده کارمند تعریف کنید؛ محاسبات حضور و بررسی مرخصی ساعتی از آن استفاده می‌کنند.

در فرم ایجاد یا ویرایش، نام، ساعت شروع و پایان را با قالب `HH:MM` و وضعیت پنجشنبه را وارد کنید. اگر پنجشنبه نیمه‌وقت است، ساعت خروج پنجشنبه نیز لازم است. پس از ذخیره، شیفت را در فهرست پیدا کنید و سپس به [پرونده کارمند](../../../hr/employees/employees.md) اختصاص دهید. تغییر شیفت ممکن است نیازمند بازبینی محاسبات حضور قبلی باشد.
