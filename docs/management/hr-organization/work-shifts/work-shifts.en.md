# Work Shifts

Path: **Management → HR & Organization → Work Shifts**. Define a shift before creating an employee record; attendance calculations and hourly-leave checks use it.

On the create or edit form, enter a name, start and end times in `HH:MM` format, and Thursday status. A half-day Thursday also requires a Thursday exit time. After saving, find the shift in the list and assign it to an [employee](../../../hr/employees/employees.en.md). Changing a shift may require reviewing previously calculated attendance.
