# Payroll Elements

Path: **Management → HR & Organization → Payroll Elements**. Create or review the earnings and deduction elements needed before defining a decree. The form requires a title (up to 100 characters), system code, category, and calculation type. Choose the code, category, and type from the form's available values. Check the saved element in the list and select it in a [salary decree](../salary-decrees/salary-decrees.en.md); changing element settings may affect future calculations.
