# Work Site Contracts

Path: **Management → HR & Organization → Work Site Contracts**. Create a [work site](../work-sites/work-sites.en.md) first. Then choose it on the contract-framework form and enter a name and unique code of at most 20 characters. You can search, view, and edit frameworks in the list. Assign a framework to an [employee](../../../hr/employees/employees.en.md) when needed; this employee field is optional.
