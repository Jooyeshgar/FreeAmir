# Salary Decrees

Path: **Management → HR & Organization → Salary Decrees**. After creating an [employee record](../../../hr/employees/employees.en.md) and [payroll elements](../payroll-elements/payroll-elements.en.md), create a decree for the employee. Employee and start date are required. An end date, if supplied, cannot precede the start date. Daily wage and each benefit value cannot be negative, and a benefit element cannot be repeated in one decree.

Name, description, end date, and daily wage are optional; set the active flag deliberately. After saving, review the decree and its dates in the list. Creating a [payroll](../../../hr/payrolls/payrolls.en.md) requires an associated decree.
